ANALYST PROFILE

      
Background & Approach

      
I’m Omkar Behera, a software engineer at APMOSYS Technologies, where I work full-time on in-depth Dynatrace implementation for multiservice application monitoring. Before that I interned at DRDO, Ministry of Defence, building interfaces for defence systems.

      
Alongside the day job I’m building web application security skills the hands-on way: a completed TryHackMe certification, a PortSwigger Web Security Academy lab, and daily practice with Burp Suite, Wireshark and Nmap. I’m working toward CEH and OSCP.

      
“Security is less about tools and more about the habit of paying attention: to the alert nobody reads, the header nobody set, the packet that shouldn’t be there.”
